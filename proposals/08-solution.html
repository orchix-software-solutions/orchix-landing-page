Intelligent Routing Matrix — Routing rules are configurable in the web app's management interface. You define skill tiers (Junior / Mid / Senior Closer), price thresholds that route premium inventory to higher tiers, language pools where agents tag themselves with languages they speak fluently, and project assignments so Project A leads never land with Project B agents. WhatsApp Strategy - Evolution API → Meta Cloud API

We will build the WhatsApp layer behind a provider-agnostic messaging service. Your application code does not care which gateway is underneath — it just calls sendTemplate(), sendMedia(), or sendText(). Today the adapter points to Evolution API. The day your Meta Business verification clears, we swap the adapter to Cloud API with near-zero application-level changes.

What this gets you on day one - Full 10-day drip campaign engine for cold leads, event-triggered messages, one-click brochure and walkthrough sharing from the CRM, full conversation threading inside each lead's timeline, bulk messaging for campaign pushes, and agent-to-buyer chat through the CRM interface.

⚠ Honest Trade-offs - Evolution API
  • It runs on a WhatsApp session — an always-on authenticated connection — not Meta's official business channel. This means it is technically against WhatsApp's Terms of Service, and in the worst case Meta can flag or ban the number.
  • To reduce that risk, we implement - warm-up schedules for new numbers, randomized send delays (no bot-like uniform intervals), per-hour and per-day rate caps, and blacklist handling so opted-out buyers never receive another message.
  • We strongly recommend using a dedicated WhatsApp number for this — not your main business number — until Cloud API is live.
  • Run the Meta Business verification process in parallel with development so the migration can happen immediately after launch.

The migration path is clean. Because the messaging service is abstracted, migration effort is expected to be limited, but final work depends on Meta approval and API/template differences. Migration is included in the post-launch support window.
