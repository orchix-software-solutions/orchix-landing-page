Critical Issues

Fix immediately — these block indexing, conversion, and AI search visibility.

1. Every CTA button uses href="#" — zero conversion paths exist Critical
Every call-to-action on the site — hero, founder section, pricing cards, footer — points to #. Clicking "Book a Free Discovery Call" goes nowhere. Conversion rate is currently 0% from organic traffic. This is also a trust signal flagged by Google QRG quality raters.
Affects: hero-section.tsx, founder-section.tsx, pricing-section.tsx, footer.tsx
2. All homepage content is inside "use client" components — invisible to AI & search crawlers Critical
Every meaningful section (hero, services, founder quote, pricing) is a client-side React component. Google, GPTBot, ClaudeBot, and PerplexityBot receive a JavaScript shell with no readable text. Root cause: the useLanguage() hook forces client rendering across the entire component tree. Fix: split each component into a server wrapper (renders English by default) + thin client wrapper (handles language switching only).
Root cause: lib/language-context.tsx → propagates to all section components
3. CaseStudiesSection is commented out in app/page.tsx Critical
Three case studies in lib/case-studies-data.ts contain the strongest E-E-A-T content on the site — concrete metrics (2.4M transactions/month, 99.98% uptime, 62% ops cost reduction, 3.2× conversion lift). They are completely unreachable. The component is built and works.
app/page.tsx:33-35 — remove comment to restore
4. Founder video src is commented out — play button renders but plays nothing Critical
The founder video widget shows a poster image and a play button. Clicking it does nothing — the src attribute is commented out. A broken interactive element actively destroys trust. Either upload founder-message.mp4 to /public/ and uncomment the src, or hide the video player entirely until the file is ready.
components/founder-section.tsx:146 — // src="/founder-message.mp4"
5. robots.txt — Missing (404) Critical
No public/robots.txt exists. Search engines and AI crawlers receive no directives. Without this file, you cannot explicitly welcome search-oriented AI bots (GPTBot, ClaudeBot, PerplexityBot) or block training-only scrapers (CCBot, anthropic-ai training bot).
6. sitemap.xml — Missing (404) Critical
No sitemap exists. With dynamic routes (/blogs/[slug], /case-studies/[slug]), a sitemap is essential for discovery. Create app/sitemap.ts using Next.js 15's built-in sitemap generation — pull slugs from blog-data.ts and case-studies-data.ts.
7. orchix-og-image.png — Now Resolved Resolved
public/orchix-og-image.png now exists. app/layout.tsx and lib/schema.ts updated to reference /orchix-og-image.png. Every social media share (LinkedIn, Twitter, Slack) fails to render a preview image — a significant trust gap during vendor evaluation.
app/layout.tsx:74 — Image exists at public/orchix-og-image.png ✓
8. Blog pages have no generateMetadata and are "use client" Critical
app/blogs/page.tsx and app/blogs/[slug]/page.tsx are client components — they cannot be statically generated and every blog post inherits only the root metadata ("OrchiX — Enterprise CRM…"). Each post needs its own unique title, description, OG tags, and canonical URL.
Compare: app/case-studies/[slug]/page.tsx correctly implements generateStaticParams + generateMetadata
9. llms.txt — Missing (404) Critical
The llmstxt.org standard (adopted by Perplexity, referenced by Anthropic) provides a crawler-readable site summary. Without it, AI systems must infer context from an unreadable client-side shell — which contains no usable text. This is a 30-minute fix with high GEO impact.

High Priority Issues

Fix within 1 week — significant impact on rankings and crawlability.

10. H1 contains zero keyword context High
The H1 reads "We ship. We stay. We deliver." — a brand slogan with no service or topic signal. Google assigns primary topic weight to the H1. Recommended replacement: "Custom CRM, ERP & SaaS Development — Built with Radical Transparency".
11. No canonical tag on any page High
metadataBase is set in layout.tsx but no explicit <link rel="canonical"> is emitted. Required on all pages, especially dynamic routes, to prevent duplicate content issues.
12. Zero JSON-LD structured data anywhere on the site High
No schema markup of any kind. As of March 2026, Google AI Mode uses Organization and Service schema to verify entity claims in AI Overviews. Missing schema = zero probability of AI Overview citations for competitive queries. Minimum required: Organization, Person (founder), Service per service, BlogPosting per blog post.
13. Page-type mismatch for all target keywords High
Every target keyword ("custom CRM development", "ERP development agency", "SaaS development agency") returns dedicated service landing pages in SERPs — not homepages. The homepage cannot rank for six transactional keywords simultaneously. Missing service pages: /services/custom-crm-development, /services/erp-development, /services/saas-development, /services/ai-integration, /services/business-automation.
14. All navigation links point to "#" High
Services, Industries, Case Studies, About, and Contact in the navbar all point to #. Crawlers cannot discover inner pages through navigation. Footer links (Services, Pricing, About, Contact) also point to #.
15. Urgency bar is date-hardcoded and will be stale High
"Only 3 seats left for April" — the month is a static string in en.json with no dynamic date logic. It becomes false from May 1. Stale urgency claims are flagged in Google's September 2025 QRG as a low-trust signal. Fix: pull the month dynamically with new Date().toLocaleString('en', {month: 'long'}).
components/urgency-bar.tsx + locales/en.json
16. 9-language setup with no hreflang tags High
Locale files exist for ar, de, en, es, fr, hi, ja, pt, zh — all served from the same URL with no hreflang annotations. Crawlers see this as potential duplicate content and cannot index non-English versions. Implement Next.js App Router i18n with /[lang]/ route segments, or add hreflang meta tags at minimum.
locales/ directory + app/layout.tsx
17. Blog [slug] route missing generateStaticParams High
app/blogs/[slug]/page.tsx does not pre-render at build time — every blog post requires dynamic rendering at request. The case studies route correctly implements this pattern. Blog posts are the highest-quality long-form content on the site and must be statically served for SEO.
